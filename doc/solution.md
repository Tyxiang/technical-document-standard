# TDS 的 Markdown 解决方案 Markdown TDS Solution

## 文档信息

在 Markdown 文档顶部加入 YAML front matter 来实现。

就像这样：

```yaml
---
文档版本: 2.15
控制范围: 公开
编制单位: forw.cc
发布日期: 2026-11-10
---
```

## 编辑器

VSCode

## 多级编号维护

VSCode 扩展 markdown-multilevel-numbering

## 不分页浏览

浏览器扩展 Markdown Reader

## 保存为 HTML

浏览器扩展 SingleFile

## 分页浏览、保存为 PDF

浏览器扩展 Markdown in Pages
